# 단톡 정리함

오픈채팅방에 쌓인 대화를 **사담을 걷어내고** 날짜별 요약 · 프롬프트 · 파일 · 링크로 정리해서 본다.
`talk/index.html` 파일 하나가 전부다. 서버도 빌드도 없다. 대화를 불러오고 정리하는 데는 API 키가 필요 없고,
문장으로 압축하는 **AI 요약만 선택 사항**으로 본인 키를 쓴다.

- 배포 주소: `https://<사용자>.github.io/<저장소>/talk/`
- 로컬에서는 파일을 그냥 브라우저로 열어도 똑같이 동작한다.

저장소 루트의 **서울 신상 레이더**(`index.html`)와는 파일도 주소도 완전히 분리돼 있다.
`deploy.yml`이 저장소 전체를 Pages에 올리기 때문에 `talk/`를 밀어 넣으면 별도 설정 없이 같이 배포된다.

## 쓰는 법

1. 카카오톡에서 대화를 내보낸다.
   - **휴대폰** — 채팅방 → ≡ → 설정 → 대화 내용 → 대화 내용 내보내기
     - `텍스트 메시지만 저장` → 글만 담긴 `.txt`
     - `모든 메시지 내부저장소에 저장` → 사진·동영상까지 담긴 `.zip` (아래 '사진·동영상' 절 참고)
   - **PC** — 채팅방 오른쪽 위 ≡ → 대화내용 → 대화 내용 저장 → 텍스트 파일 (사진은 안 담긴다)
2. 받은 `.txt`나 `.zip`을 사이트에 끌어다 놓는다. 방 하나가 위쪽 탭 하나가 된다.
3. 다음에 또 내보내서 넣으면 **겹치는 메시지는 빼고 새것만** 붙는다. 내보내기 방식에 따라 방 이름 끝에
   인원수가 붙기도 하는데, 이름이 달라도 **내용이 30% 넘게 겹치면 같은 방으로 보고 합친다.**
   새 방을 만들어 버리면 그 방에 붙여둔 AI 정리가 딸려오지 않기 때문이다.

불러온 대화는 브라우저의 IndexedDB에 남으므로 새로고침해도 유지된다. 방 탭의 `×`로 지운다.

## 화면 네 개

| 탭 | 하는 일 |
| --- | --- |
| **요약** | 왼쪽에 날짜별 핵심 주제 카드. 카드를 누르면 가운데에 **그 시점의 실제 대화**가 펼쳐지고 해당 메시지가 노랗게 표시된다. 오른쪽에는 그 덩어리의 알맹이 발언·링크·파일이 정리돼 붙는다. |
| **자료함** | 프롬프트 · 파일 · 링크만 모아 날짜별로 본다. 프롬프트는 통째로 복사할 수 있다. zip으로 넣었으면 사진·동영상도 여기 붙는다. |
| **월간** | 그 달의 날짜별 AI 정리를 묶어 한 달 흐름을 만든다. 아래 'AI 요약' 절 참고. |
| **검색** | 방 전체 본문 검색. 결과를 누르면 그 날 대화 맥락으로 바로 이동한다. |

요약 탭은 세 칸이다. 왼쪽 **개요**(무슨 얘기가 있었는지), 가운데 **원문**, 오른쪽 **정리**(고른 덩어리의
속을 펼쳐 보여줌). 화면이 1240px보다 좁으면 오른쪽 정리 칸은 자동으로 접힌다.

가운데 원문에서 사담·봇 안내·입퇴장이 세 줄 이상 연달아 나오면 `잡담 7줄 · 입·퇴장 4줄 접힘` 한 줄로
접힌다. 눌러서 그 자리에서 펼칠 수 있다. 오픈채팅방은 이게 하루 수백 줄이라 접지 않으면 원문이 봇으로 도배된다.

날짜나 요약 카드를 눌러도 왼쪽 목록은 **누른 자리를 그대로 유지한다.** 지난 날짜를 보려고 한참
내려간 뒤에 눌렀는데 맨 위로 튀어 오르는 일이 없다.

## 불러오는 데 API 키가 필요 없는 이유

- 카카오는 **오픈채팅 대화를 읽어오는 공개 API를 제공하지 않는다.** 어떤 서비스를 쓰든 입구는 결국 내보내기 파일이다.
- 날짜 구분은 내보낸 파일에 이미 들어 있다(`--------------- 2026년 9월 1일 월요일 ---------------`).
  API를 부를 일이 아니라 파싱할 일이다.
- 사담 걸러내기·자료 모으기·검색은 이 페이지 안에서 규칙 기반으로 처리한다.
  **대화 내용이 브라우저 밖으로 나가지 않는다.** 아래 'AI 요약'만 예외이고, 그건 켤지 말지를 직접 고른다.

## 사담을 걸러내는 기준

먼저 **아예 빼는 것**이 있다. 점수와 무관하게 요약에서 통째로 제외한다.

- **봇 안내** — 보낸 사람 이름이 `오픈채팅봇` 같은 계정(`RE_BOT_USER`)
- **반복 안내** — 같은 문구가 그 방에 3번 이상 올라온 25자 넘는 글(`markRepeats`).
  입장할 때마다 자동으로 나가는 인사가 여기서 걸린다
- **입·퇴장** — 시스템 줄
- **모집·신청 공지** — 광고 신호(`PROMO_CUES`)가 둘 이상이거나, 하나라도 있으면서 링크가 붙은 글.
  단어 하나로 자르면 "세미나 자료 어디 있나요?" 같은 진짜 질문까지 날아가므로 신호를 센다

이렇게 남은 것에 `scoreMessages()`가 점수를 매기고, 문턱(`KEEP`)을 넘은 것만 요약에 올라간다.

**점수를 올리는 것** — 링크, 첨부 파일, 프롬프트 형태의 긴 글, 주제 사전(`TOPICS`) 적중,
10분 안에 여러 사람이 반응한 메시지, 물음표로 끝나는 긴 질문.

**점수를 내리는 것** — `ㅋㅋ` `넵` `감사합니다` 같은 리액션(`RE_CHATTER`), 14자 미만의 짧은 말.

여기에 `expandKeep()`이 한 겹 더 붙는다. 질문만 남고 정작 답변이 사담으로 밀려나는 일이 잦아서,
남긴 메시지 뒤 10분 안에 붙는 35자 이상의 리액션 아닌 말은 같은 흐름으로 끌어온다.

빠진 메시지도 **사라지지는 않는다.** 가운데 원문에는 접힌 채로 그대로 있고, 링크와 파일은
자료함에 계속 모인다. 빼는 건 요약에서만이다.

문턱이 뻑뻑하거나 헐거우면 파일 안의 상수를 만지면 된다.

```js
const KEEP = 2.6;          // 낮추면 더 많이 남는다
const GAP_MIN = 45;        // 이 시간(분) 이상 벌어지면 일단 끊는다
const MERGE_GAP_MIN = 60;  // 끊었어도 주제가 겹치고 이만큼 안에 이어지면 도로 합친다
```

한 흐름으로 이어진 대화가 시간만 벌어졌다고 쪼개지면 같은 얘기를 두 번 읽어야 한다. 그래서 끊은 뒤
**주제가 겹치는 이웃 덩어리를 도로 합친다.** 다만 하루가 통째로 한 덩어리가 되지 않게 3시간·25건에서
멈추고, 날짜는 절대 넘지 않는다.

관심사가 다르면 `TOPICS` 배열에 `["이름", /정규식/i]` 한 줄을 더한다. 카드 아래 붙는 분류 꼬리표가 여기서 나온다.

## 처리하는 파일 형식

카카오톡 내보내기는 기기마다 형식이 다르다. 셋 다 처리한다.

```
PC          [홍길동] [오후 10:23] 내용
안드로이드   2026년 9월 1일 오후 10:23, 홍길동 : 내용
아이폰       2026. 9. 1. 오후 10:23, 홍길동 : 내용
```

여러 줄짜리 메시지(프롬프트가 대개 그렇다)는 이어붙이고, 옛날 PC판이 뱉는 EUC-KR 인코딩도
깨진 글자 비율을 보고 자동으로 되읽는다.

## AI 요약 (선택)

규칙만으로는 **원문에서 문장을 발췌**하는 것까지가 한계다. "이 대화는 블로그 자동화에서 AI 티가
나는 문제를 다뤘다" 같은 새로 쓴 문장은 LLM이 있어야 나온다. 그래서 AI 요약은 선택 기능으로 붙였다.

오른쪽 위 **AI 요약 설정**에서 제공사와 본인 API 키를 넣는다. 키는 이 브라우저의 `localStorage`에만
저장된다 — 코드에도, 저장소에도, 깃허브에도 들어가지 않는다.

| 제공사 | 성격 |
| --- | --- |
| 클로드 (Anthropic) | 유료. 보낸 내용을 모델 학습에 쓰지 않는다 |
| 제미나이 (Google) | 무료 등급이 있다. 다만 무료 등급은 보낸 내용이 제품 개선에 쓰일 수 있다 |

**여기서만 대화가 바깥으로 나간다.** 그것도 전체가 아니라 걸러 남긴 알맹이만, 메시지당 500자로
잘라서 보낸다. 나머지 기능(사담 걸러내기, 자료함, 검색)은 전부 브라우저 안에서 끝난다.

- **날짜별** — 요약 탭에서 날짜를 고르고 `AI로 정리`. 카드 제목이 압축된 한 줄로 바뀌고,
  오른쪽 정리 칸에 문단 요약과 기억할 항목이 붙는다.
- **월별** — 월간 탭. 그 달의 날짜별 정리를 재료로 한 달 흐름을 만든다.
  날짜별 정리가 하나도 없으면 만들 수 없다.

결과는 IndexedDB에 남으므로 같은 날을 두 번 부르지 않는다. `AI로 다시 정리`를 누를 때만 다시 부른다.

## 카드 제목을 만드는 두 갈래

AI를 붙이지 않으면 `keyphrase()`가 덩어리에서 자주·여럿이 쓴 명사를 뽑아 이어 붙인다
(`블로그 · 자동화 · 클로드`). 조사를 떼어 `자동화를`과 `자동화가`를 같은 말로 세고,
서술어와 관형형은 후보에서 뺀다. 질문에 나온 말에는 가중치를 준다.

명사가 안 잡히는 짧은 덩어리는 `headline()`이 원문 한 문장으로 대신한다. 이때는 질문이 곧 주제이므로
물음표가 붙은 문장을 먼저 고르고, 여러 덩어리를 합친 흐름이라면 **대화를 연 첫 질문**을 쓴다.
`파일: xxx.pdf` 한 줄짜리는 후보에서 빼고 설명한 쪽을 고른다.

AI를 붙이면 그 자리에 진짜 압축 제목이 들어가고 카드에 `AI` 표시가 붙는다.

## 사진·동영상 (zip으로 넣기)

카톡 휴대폰 내보내기의 **모든 메시지 내부저장소에 저장**은 대화 txt와 사진·동영상을 zip 하나로
묶어 폰에 남긴다. 그 zip을 그대로 넣으면 자료함에 **사진·동영상** 칩이 생긴다.

- zip은 외부 라이브러리 없이 브라우저의 `DecompressionStream`으로 푼다.
- 안에서 가장 큰 `.txt`를 대화로 읽고, 나머지 중 이미지·영상·음성만 골라 IndexedDB에 담는다.
- 파일 이름이 내용 해시라 이름만으로는 날짜조차 알 수 없다. 어느 메시지의 사진인지는 두 단계로 가린다.
  1. **대화에 파일 이름이 그대로 적혀 있으면 그것으로 맞춘다.** 가장 확실하다.
  2. 이름이 없으면, 대화 속 `사진` 자리 수와 파일 수가 **같을 때만** 담긴 순서대로 짝짓는다.
     `사진 3장`은 세 자리로 센다.
  짝이 지어지면 자료함뿐 아니라 대화 원문의 그 자리에 사진이 붙는다.
- 둘 다 안 되면 파일 이름의 날짜, 그다음 압축파일이 파일마다 담아 두는 저장 시각 순으로 기대고,
  그것도 없으면 '날짜를 알 수 없는 것'으로 모은다. 어느 방법으로 갔는지는 불러올 때 알린다.
- 동영상은 한 개가 40MB를 넘으면 저장 공간을 다 먹으므로 건너뛰고, 몇 개를 건너뛰었는지 알린다.

`텍스트 메시지만 저장`으로 뽑은 txt에는 사진이 아예 들어있지 않다. 그때는 `사진`이라는 표시만 남는다.
