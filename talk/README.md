# 단톡 정리함

오픈채팅방에 쌓인 대화를 **사담을 걷어내고** 날짜별 요약 · 프롬프트 · 파일 · 링크로 정리해서 본다.
`talk/index.html` 파일 하나가 전부다. 서버도, 빌드도, API 키도 필요 없다.

- 배포 주소: `https://<사용자>.github.io/<저장소>/talk/`
- 로컬에서는 파일을 그냥 브라우저로 열어도 똑같이 동작한다.

저장소 루트의 **서울 신상 레이더**(`index.html`)와는 파일도 주소도 완전히 분리돼 있다.
`deploy.yml`이 저장소 전체를 Pages에 올리기 때문에 `talk/`를 밀어 넣으면 별도 설정 없이 같이 배포된다.

## 쓰는 법

1. 카카오톡에서 대화를 내보낸다.
   - **휴대폰** — 채팅방 → 오른쪽 위 ≡ → 설정(톱니) → 대화 내용 → 대화 내보내기 → 텍스트만 보내기
   - **PC** — 채팅방 오른쪽 위 ≡ → 대화내용 → 대화 내용 저장 → 텍스트 파일
2. 받은 `.txt`를 사이트에 끌어다 놓는다. 방 하나가 위쪽 탭 하나가 된다.
3. 다음에 또 내보내서 같은 이름으로 넣으면 **겹치는 메시지는 빼고 새것만** 붙는다.

불러온 대화는 브라우저의 IndexedDB에 남으므로 새로고침해도 유지된다. 방 탭의 `×`로 지운다.

## 화면 세 개

| 탭 | 하는 일 |
| --- | --- |
| **요약** | 왼쪽에 날짜별 핵심 주제 카드. 카드를 누르면 오른쪽에 **그 시점의 실제 대화**가 펼쳐지고 해당 메시지가 노랗게 표시된다. |
| **자료함** | 프롬프트 · 파일 · 링크만 모아 날짜별로 본다. 프롬프트는 통째로 복사할 수 있다. |
| **검색** | 방 전체 본문 검색. 결과를 누르면 그 날 대화 맥락으로 바로 이동한다. |

## API 키가 필요 없는 이유

- 카카오는 **오픈채팅 대화를 읽어오는 공개 API를 제공하지 않는다.** 어떤 서비스를 쓰든 입구는 결국 내보내기 파일이다.
- 날짜 구분은 내보낸 파일에 이미 들어 있다(`--------------- 2026년 9월 1일 월요일 ---------------`).
  API를 부를 일이 아니라 파싱할 일이다.
- 요약은 이 페이지 안에서 규칙 기반으로 처리한다. **대화 내용이 브라우저 밖으로 나가지 않는다.**

## 사담을 걸러내는 기준

`scoreMessages()`가 메시지마다 점수를 매기고, 문턱(`KEEP`)을 넘은 것만 요약에 남는다.

**점수를 올리는 것** — 링크, 첨부 파일, 프롬프트 형태의 긴 글, 주제 사전(`TOPICS`) 적중,
10분 안에 여러 사람이 반응한 메시지, 물음표로 끝나는 긴 질문.

**점수를 내리는 것** — `ㅋㅋ` `넵` `감사합니다` 같은 리액션(`RE_CHATTER`), 14자 미만의 짧은 말, 입퇴장 시스템 메시지.

여기에 `expandKeep()`이 한 겹 더 붙는다. 질문만 남고 정작 답변이 사담으로 밀려나는 일이 잦아서,
남긴 메시지 뒤 10분 안에 붙는 35자 이상의 리액션 아닌 말은 같은 흐름으로 끌어온다.

문턱이 뻑뻑하거나 헐거우면 파일 안의 상수를 만지면 된다.

```js
const KEEP = 2.6;     // 낮추면 더 많이 남는다
const GAP_MIN = 25;   // 이 시간(분) 이상 벌어지면 다른 주제로 끊는다
```

관심사가 다르면 `TOPICS` 배열에 `["이름", /정규식/i]` 한 줄을 더한다. 요약 카드 제목이 여기서 나온다.

## 처리하는 파일 형식

카카오톡 내보내기는 기기마다 형식이 다르다. 셋 다 처리한다.

```
PC          [홍길동] [오후 10:23] 내용
안드로이드   2026년 9월 1일 오후 10:23, 홍길동 : 내용
아이폰       2026. 9. 1. 오후 10:23, 홍길동 : 내용
```

여러 줄짜리 메시지(프롬프트가 대개 그렇다)는 이어붙이고, 옛날 PC판이 뱉는 EUC-KR 인코딩도
깨진 글자 비율을 보고 자동으로 되읽는다.
