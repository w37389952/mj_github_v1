체크를 저장소에 저장하기

체크한 할 일을 저장소의 dashboard/checks.json에 적어 두면, 다른 기기와 Claude 창도 끝난 일로 알아봐요. 그러려면 이 브라우저에 GitHub 열쇠(토큰)를 한 번 넣어야 해요. 폰과 PC는 따로 한 번씩 넣어요.

  1. GitHub 토큰 만들기를 열어요.
  2. Token name은 아무거나(예: 현황판 체크), Expiration은 1년 정도로.
  3. Repository access에서 Only select repositories → mj_github_v1만 골라요.
  4. Permissions → Repository permissions → Contents를 Read and write로.
  5. Generate token을 누르고 나온 github_pat_…을 아래에 붙여 넣어요.

열쇠는 이 브라우저 안에만 저장되고 저장소나 페이지에는 올라가지 않아요.
